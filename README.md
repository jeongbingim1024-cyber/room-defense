# 룸 디펜스 (Room Defense)

> 세상은 망했다. 내 방만 빼고.

포스트 아포칼립스 방치형 룸 디펜스. 사방에서 몰려오는 벌레 떼로부터 내 방과 침대를 지키는 픽셀 아트 타워 디펜스입니다. 한국어·English 지원, PC·모바일 겸용.

- 플레이: https://bin0707.itch.io/room-defense
- 변경 내역: [CHANGELOG.md](CHANGELOG.md)

## 실행 방법

`index.html`을 브라우저로 열면 바로 실행됩니다. (설치 필요 없음, 파일 하나)

## 조작키

| 키 | 동작 |
|---|---|
| Enter (시작 화면) | 게임 시작 |
| 1 ~ 9 | 타워 선택 |
| 마우스 클릭 / 탭 | 빈 칸에 타워 설치, 설치된 타워는 업그레이드·판매 메뉴 |
| 드래그 | 아래 타워 목록에서 끌어다 설치, 설치된 타워 이동 (겹치면 자리 교환) |
| Space | 웨이브 바로 시작 |
| U | 울타리 강화 |
| R | 침대 수리 (게임 오버 후엔 다시 시작) |
| F | 게임 속도 |
| T | 타워 목록 접기·펴기 |
| S | 이번 판 능력치 |
| M | 딜량 미터기 |
| H | UI 숨기기 |
| ESC / P | 일시정지 |

단축키는 설정에서 바꿀 수 있습니다.

## 화면

- 게임 화면은 창 비율에 맞춰 넓어지고, 벌레는 화면 밖에서 들어옵니다.
- 타워 목록은 화면 아래 서랍에 있고 TOWERS 탭으로 접었다 폈다 합니다. (세로 화면에서는 아래에 고정)

## 타워 29종 (일반 · 희귀 · 영웅 · 전설)

기본 9계열(강풍기, 레이저 포탑, 끈끈이 덫, 뿅망치 기계, 모기향, 전기 파리채, 테슬라 코일, 대포, 고무줄 새총)과 변형 20종.

- 통조림으로 뽑고, 9칸 엔트리(일반 3 · 희귀 3 · 영웅 2 · 전설 1)를 직접 구성합니다. 판 안에서는 웨이브를 깰수록 칸이 열립니다.
- 중복을 뽑으면 ★이 오릅니다 (★마다 공격력 +12%, 최대 ★5, 그 뒤엔 배터리 환급).
- 배터리로 타워 레벨업 (Lv마다 공격력 +5%, 최대 Lv = ★×2). ×1 · ×5 · 최대 단위 선택.
- 숙련(판 안): 벌레를 잡을수록 그 판에서 공격력이 오릅니다.
- 타워 업적(영구): 종류별 누적 처치 100~30,000마리마다 배터리와 공격력 +3%.
- 전설 6종은 특수 능력: 고무줄 새총 급소 저격 · 레일건 관통탄 · 불꽃놀이 피날레 · 피뢰침 낙뢰 · 태양광 레이저 과열 · 철거용 해머 지진.

## 타워 칸 · 울타리 11단계

- 타워 칸은 기본 8칸. 울타리를 LV3 · LV5 · LV7 · LV9로 올릴 때마다 2칸씩 늘어 최대 16칸.
- 울타리: 나무 울타리 → 보강 울타리 → 철조망 → 강철 펜스 → 전기 펜스 → 레이저 펜스 → 플라스마 방벽 → 황금 결계 → 다이아 장벽 → 양자 방어막 → 침대 수호 결계. 오를수록 받는 피해 감소, 가시 피해, 최대 HP가 올라갑니다.

## 적 · 보스 · 엔딩

- 개미, 모기, 쥐, 바퀴벌레, 폭탄먼지벌레(원거리), 파리, 거미, 달팽이, 지네, 나방, 말벌(웨이브 15), 장수풍뎅이(18), 벼룩(21).
- 5웨이브마다 대형 보스, 일반 웨이브에 가끔 정예 보스. 대형 보스는 90초 안에 못 잡으면 게임 오버.
- 웨이브 100 최종 보스를 잡으면 엔딩 (처음엔 배터리 +300), 그 뒤로 무한 모드.
- 보스 도감 30종: 처음 잡으면 등록되고 배터리 보상.

## 시작 화면 메뉴

- **뽑기**: 타워 · 캐릭터 · 장비를 통조림으로 뽑습니다 (1 · 10 · 100개). 통조림을 딸수록 뽑기 레벨이 올라 높은 등급 확률이 영구히 오릅니다.
- **강화**: 배터리로 영구 강화 8종(비상금, 튼튼한 침대, 정밀 조준, 좋은 시력, 재활용 달인, 단골 철물점, 급소 노리기, 한계 돌파)과 기능 해금(캐릭터 2번 칸, 자동 수리, 무료 다시 뽑기, 능력 4지선다).
- **보관함**: 캐릭터 장착·강화, 장비, 타워 엔트리·레벨업, 도감.

## 캐릭터 24명

- 일반 9 · 희귀 7 · 영웅 5 · 전설 3. 뽑기로 얻거나 배터리로 삽니다 (일반 800 · 희귀 2500 · 영웅 6000 · 전설 15000).
- 중복은 ★ (★마다 능력 +10%), 배터리 강화는 레벨마다 능력 +8% (최대 Lv11).
- 캐릭터마다 짝 타워 계열과 장비 부위가 있어 강화할수록 시너지가 커집니다.
- 장착한 캐릭터는 게임 화면 침대(1번 칸)와 바닥(2번 칸)에 나옵니다.

## 장비

- 6부위(투구, 상의, 하의, 신발, 방패, 무기) × 7등급(일반 · 고급 · 희귀 · 영웅 · 전설 · 신화 · 초월) × ★4 = 168종.
- 같은 등급 안에서는 ★이 높을수록 세지만, ★4도 한 등급 위 ★1보다는 약합니다.
- 중복은 +1 강화(최대 +5). +5 뒤 중복 5개를 모으면 한 등급 위 같은 ★ 장비 1개로 합성 (배터리 환급 없음).
- 장비 탭의 '최고 장비 자동 장착'으로 부위마다 가장 좋은 장비를 낍니다.

## 그 밖에

- 10웨이브마다 이번 판 능력 3개 중 1개 선택 (다시 뽑기 가능).
- 업적: 단계형 퀘스트, 깰 때마다 배터리.
- 온라인 순위표, 구글 로그인 클라우드 저장, 기록 옮기기 코드, 쿠폰, 공지.
- 설정: 언어, 배경음악·효과음, 화면 흔들림, 피해 숫자, 색약 모드, 자동 웨이브, 단축키 바꾸기 등.
- 소리는 파일 없이 Web Audio로 만든 8비트 음악·효과음입니다.

## 코드 구조 (배운 개념 연결)

- **OOP**: `Tower` 클래스를 상속해 타워 계열별 공격 방식 구현
- **FSM (유한 상태 기계)**: 적의 상태 이동(move) → 울타리 공격(attack)
- **큐**: 웨이브마다 스폰할 적을 큐에 넣고 차례로 꺼냄
- **유클리드 거리**: 타워 사거리 안에 적이 있는지 판정
